# Relational Database with SQLAlchemy

## Overview
This project demonstrates how to create and manage a relational database using Python and SQLAlchemy.

## Features
- Create tables: User, Product, Order
- Define relationships between tables
- Insert sample data
- Perform CRUD operations:
  - Retrieve users, products, and orders
  - Update product price
  - Delete a user
- Bonus:
  - Track order shipment status
  - Query unshipped orders
  - Count orders per user

## Technologies Used
- Python
- SQLAlchemy
- SQLite

## How to Run

1. Install dependencies
-Install SQLAlchemy
-pip install SQLAlchemy

2. Type 'python main.py'
